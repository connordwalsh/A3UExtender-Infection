# Occupant integration impact matrix

Research baseline: Ultimate 12.4.2, commit
[`c7c8247672ed5e7d4aa317d47efb371c41de4e7d`](https://github.com/Antistasi-Ultimate-Community/A3-Antistasi-Ultimate/tree/c7c8247672ed5e7d4aa317d47efb371c41de4e7d/A3A/addons).
The [version refresh](VERSION_REFRESH_12.4.2.md) records the source delta from 12.4.1.
This is the S0-3 integration map. Treatments below are proposed work, not claims
that overrides or acceptance tests already exist. The S3 route disposition and
S4 mission-by-mission catalog must expand the relevant rows before acceptance.

Paths are relative to that revision's `A3A/addons/` directory. Prefixes: `C:` =
`core/functions/`, `P:` = `patcom/functions/`, `S:` = `scrt/`, `U:` =
`ultimate/functions/`, `T:` = `core/Templates/`. The accompanying
[source manifest](../../evidence/sprint-0/impact-sources-12.4.2.json) verifies each named
owner file and records its hash. An owner is the entry point to audit; listing it
does not imply that all of its callees have already been proven safe.

## Boundaries to preserve

Every override needs both an Infection-template guard and the relevant side or
object-ownership guard. WEST alone is insufficient: a normal NATO Occupant
campaign must continue to work with this addon loaded but unselected. Invader,
Rival, civilian and player assets cannot be inferred solely from an inherited
unit classname's configured side; use the runtime group and campaign metadata.

The prepared-class smoke test verifies initial server ownership, not HC transfer
or client authority. Event names containing `server` are not proof of network
delivery to owner 2; inspect the caller and `C:Events/fn_triggerLocalEvent.sqf`.
Post-spawn events cannot prevent a bad spawn that already happened.

All extension-origin infected requests, including outbreak missions, boss adds
and reinforcement, must converge on the same server budget. Reserve capacity
before asynchronous creation; release on failure and every cleanup path. Do not
use a periodic count alone as a reservation system.

The impact matrix identifies 24 integration areas. S0-3 remains in progress
until the remaining caller audit and self-review verify coverage; this document
is not the later S3 signed route disposition or the S4 complete mission catalog.
